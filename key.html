How to get a key for the AI Assistant.

This add-on is completely non-profit - I earn nothing from it. However, AI API calls have unavoidable costs that I can't cover for all users for free. With your own key, you pay only for what you actually use.

See YouTube Tutorial
  • 1

    Go to the OpenRouter website

    Visit openrouter.ai

  • 2

    Sign up or log in

    Create an account (Sign Up) or log into your existing account (Log In).

  • 3

    Add credits to your account

    Go to the Billing or Credits section. You need to add at least $5 to use the API. Complete the payment process.

  • 4

    Open the dashboard

    After adding credits, return to your dashboard.

  • 5

    Navigate to API Keys

    Find “API Keys” in the menu and click on it.

  • 6

    Create a new API key

    Click “Create Key” or “New API Key”. Optionally give it a name.

  • 7

    Copy and store your API key

    The key is shown only once (but you can create a new one anytime). Save it securely.

  • 8

    Use the API Key in the Synapse Pro Add-On

    Copy and paste it into the license key dialog pop-up inside Anki. Click OK and use the AI Assistant!

Important:

• You must have at least $5 in credits to use the API.
• Never share your API key publicly.
